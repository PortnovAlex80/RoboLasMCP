RoboLas Installer
=================

Run RoboLasInstaller.exe, select the Topomatic installation and a .tpm
package, then click INSTALL NOW. The installer requires administrator rights.

Build
-----
build.bat creates a Debug EXE. publish.bat builds Release and copies the
EXE to ..\dist. Both target .NET Framework 3.5 and run on CLR 2. Windows
must have the .NET Framework 3.5 feature enabled. The EXE has no .NET 8
runtime dependency.

Package format
--------------
The installer accepts the ZIP subset generated by build/package.ps1:
single-volume archives, stored or Deflate entries, ASCII entry names,
no ZIP64, no data descriptors, no encryption, no entry extras or comments.
Maximum archive size is 256 MiB, maximum entry size 128 MiB, and maximum
sum of uncompressed sizes 1 GiB. It verifies every entry's CRC and size
before creating any installation file, stages files on destination volumes,
and rolls back committed destinations if installation fails.
