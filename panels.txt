Для создания собственной панели и обновления данных необходимо:

- прописать панель в секции "panels" в файле plugin вашего модуля
- реализовать две команды - первая создаёт контрол панели, вторая отвечает за его обновление.
- реализовать контрол панели, в базе это любой наследник от Control, в Вашем случае вы скорее всего унаследуете его от UserControl
чтобы можно было там размещать элементы управления


Например, в файле plugin прописываем свою панель

{
    ...
    "panels": {
        //Имя-идентификатор панели - должно быть уникальным (может быть использовано для добавления тулбара на панель)
        "my_panel": {
            "title": "Название моей панели",
            "description": "Описание моей панели в подсказке",
            "cmd": "create_my_panel", //команда для создания контрла панели
            "icon": "ic_my_panel", //иконка
            "refresh": "refresh_my_panel", //команда для обновления данных моей панели
            "docking": 0 //Положение панели по умолчанию (слева, справа, снизу)
        }
    }
    ...
}
