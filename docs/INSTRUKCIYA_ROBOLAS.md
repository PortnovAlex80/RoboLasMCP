## Установка плагина

1. Скопируйте файл `LAS_TERRAIN.dll` в папку плагинов Topomatic Robur
2. Перезапустите Topomatic
3. Плагин появится в меню «Дополнения»

---

## Обзор интерфейса

После установки плагина на панели инструментов Topomatic появляются новые команды:

| Команда | Иконка | Описание |
|---------|--------|----------|
| **Вырезать LAS** | ✂️ | Загрузка LAS-файла и вырезка по коридору трассы |
| **Рассчитать сечение** | 📐 | Расчёт характерных точек по поперечным сечениям |
| **Фильтрация** | 🔍 | Применение фильтров к облаку точек |
| **Экспорт** | 📤 | Выгрузка результатов в слои Topomatic |

## Загрузка LAS-файлов

### Поддерживаемые форматы

- **LAS** — бинарный формат облака точек
- **LAZ** — сжатый формат LAS

### Ограничения

- Максимальный размер файла: 50 ГБ
- Максимальное количество точек: 1 600 000+

### Порядок загрузки

1. Нажмите кнопку **«Вырезать LAS»** на панели инструментов
2. Выберите LAS-файл в диалоговом окне
3. Дождитесь завершения загрузки (индикатор прогресса)
4. Облако точек отобразится в окне Topomatic

> **Примечание:** Для файлов размером более 10 ГБ время загрузки может составлять 30–60 секунд.

## Вырезка по коридору трассы

### Назначение

Вырезка облака точек в границах коридора трассы для дальнейшей обработки.

### Параметры

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| **Ширина коридора** | Ширина зоны вырезки по обе стороны от оси трассы | 1–100 м |
| **Шаг вдоль трассы** | Шаг дискретизации по длине трассы | 0.5–50 м |
| **Буфер** | Дополнительный отступ от границ | 0–10 м |

### Порядок действий

1. Выберите трассу в проекте Topomatic
2. Нажмите **«Вырезать LAS»**
3. Укажите параметры коридора
4. Нажмите **«ОК»**
5. Дождитесь завершения обработки

## Фильтрация данных

### Типы фильтров

#### 1. Статистический фильтр (Min/Max)

Удаление точек, выходящих за пределы заданного диапазона высот.

| Параметр | Описание |
|----------|----------|
| **Мин. высота** | Нижний порог высоты (м) |
| **Макс. высота** | Верхний порог высоты (м) |

**Применение:** удаление аномальных точек (ЛЭП, птицы, самолёты)

#### 2. B-сплайн сглаживание

Сглаживание поверхности с использованием B-сплайна.

| Параметр | Описание |
|----------|----------|
| **Степень сплайна** | Степень сглаживания | 1–5 |
| **Шаг сетки** | Размер ячейки сетки (м) | 0.5–10 м |

**Применение:** устранение шумов, сглаживание рельефа

#### 3. Прореживание

Снижение плотности облака точек без потери точности.

| Параметр | Описание |
|----------|----------|
| **Метод** | Равномерное / случайное прореживание |
| **Фактор** | Процент оставляемых точек | 10–100% |

**Применение:** оптимизация размера файла для быстрой работы

#### 4. Разделение на зоны

Разделение облака точек на основную трассу и обочины.

| Зона | Описание |
|------|----------|
| **Основная трасса** | Центральная часть проезжей части |
| **Обочины** | Боковые части коридора |

**Применение:** раздельная обработка разных частей коридора

### Порядок применения фильтров

1. Загрузите LAS-файл
2. Выполните вырезку по коридору
3. Нажмите **«Фильтрация»**
4. Выберите тип фильтра
5. Укажите параметры
6. Нажмите **«Применить»**
7. Результат отобразится в окне

> **Примечание:** Фильтры можно применять последовательно для достижения требуемого результата.

## Расчёт поперечных сечений

### Назначение

Расчёт характерных точек рельефа по поперечным сечениям вдоль трассы для последующего построения цифровой модели рельефа.

### Параметры расчёта

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| **Шаг сечений** | Расстояние между поперечными сечениями | 1–100 м |
| **Шаг по сечению** | Шаг между точками в пределах сечения | 0.5–10 м |
| **Метод интерполяции** | Линейный / B-сплайн / IDW | — |
| **Масштаб высот** | Коэффициент усиления контраста | 1–10x |

### Порядок расчёта

1. Выполните вырезку и фильтрацию LAS
2. Нажмите **«Рассчитать сечение»**
3. Укажите шаг сечений и параметры интерполяции
4. Нажмите **«ОК»**
5. Дождитесь завершения расчёта
6. Результаты отобразятся на поперечных профилях

### Просмотр результатов

Результаты расчёта можно просмотреть на поперечных профилях Topomatic:

- Характерные точки рельефа
- Цифровая модель рельефа
- Изолинии высот

## Масштабирование высот

### Назначение

Усиление контраста рельефа для выявления скрытых структурных линий.

### Параметры

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| **Коэффициент** | Масштабный множитель для высот | 1–10x |
| **Базовая высота** | Высота, от которой применяется масштабирование | 0–1000 м |

### Применение

- Выявление малых форм рельефа
- Обнаружение скрытых структурных линий
- Улучшение визуализации

## Решение проблем

### Файл не загружается

**Возможные причины:**
- Неверный формат файла (только LAS/LAZ)
- Файл повреждён
- Недостаточно памяти

**Решение:** Проверьте формат файла, попробуйте файл меньшего размера.

### Фильтрация не даёт результата

**Возможные причины:**
- Слишком узкие диапазоны фильтра
- Все точки отфильтрованы

**Решение:** Расширьте диапазоны фильтра, уменьшите степень сглаживания.

### Экспорт не работает

**Возможные причины:**
- Не выбран целевой слой
- Нет рассчитанных сечений

**Решение:** Выполните расчёт сечений перед экспортом.
